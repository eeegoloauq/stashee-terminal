
## Install

| System | File |
|---|---|
| Fedora | `.rpm`: `sudo dnf install ./stashee-*.rpm` |
| Arch | `.pkg.tar.zst`: `sudo pacman -U ./stashee-*.pkg.tar.zst` |

Needs tmux. [COPR](https://copr.fedorainfracloud.org/coprs/eeegoloauq/stashee/) and the
[AUR](https://aur.archlinux.org/packages/stashee) keep it updated.
